# Examples — real paperdigest output

Unedited output from live runs of paperdigest, committed as-is so you can see
exactly what the tool produces before installing anything.

## [`9b-attention-is-all-you-need/`](9b-attention-is-all-you-need/)

Both pipelines (`digest` and `scaffold`) run against **"Attention Is All You
Need"** (arXiv:1706.03762) using a **local 9B model** — no cloud API. Contains
the Obsidian `vault/` (digest output), the `scaffold-project/` (scaffold
output), and the run `logs/`. See that folder's README for the model, the
environment, and the exact commands to reproduce it.
